# 快速开始

## 1. 准备软件和授权

1. 用管理员用户名和密码登录，在“系统设置”填写客户可访问的 HTTPS 对外服务地址。
2. 在“软件”中新建软件；Docker 程序填写公开镜像名，如 `your-org/your-app`，不带标签。
3. 添加用户，在“授权”发放授权码，设置有效期及同时运行的实例数；默认限制 1 个实例。
4. 如需免授权码试用，在软件中开启“启用免授权码试用”；参数在系统设置统一配置，[申领与限制](?tab=protocol#64-免授权码试用)见协议。

## 2. 复制接入配置

打开软件“接入程序”，点击“显示接入配置”或“复制接入配置”，把配置写入源码常量。

接入配置可以公开，但它是信任根，必须编译进程序，不能让客户通过环境变量、文件或响应替换。客户只需提供 `AUTHGO_LICENSE`；启用试用时可留空。

## 3. 安装 SDK 并接入业务

1. 打开 [SDK 示例](?tab=sdk)，选择 Go、Python、Node.js、Rust、Java、C# 或 PHP，从仓库源码安装 SDK。
2. 复制高层守卫示例，将业务放在守卫允许的区域；关键功能用本地票据校验，不仅判断成功布尔值。
3. 常驻程序处理正常退出并释放席位，最终授权失败退出 77；PHP 请求式返回 HTTP 503，不结束服务进程。
4. 需要显示公告时，使用示例中的 SDK 公告方法，仅展示通过签名验证的内容。无 SDK 网页入口及限制见[公告接口](?tab=protocol#65-公告与公开读取接口)。

## 4. 构建、发布与交付

1. Docker 程序按[Docker 接入](?tab=docker)复制模板、构建镜像，也可在后台通过 GitHub Actions 发布。
2. 交付镜像名、版本、Compose 文件、授权码和[给客户的运行说明](?tab=customer)。
3. 每个实例保留独立缓存卷；首次激活必须联网，断网处理见[离线与故障](?tab=offline)。

不要记录授权码、配置串、令牌或私钥。客户端由客户控制，代码加密不能保证绝对防破解。
